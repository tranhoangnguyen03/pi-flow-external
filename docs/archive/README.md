# Historical Archive

This directory contains dated planning documents, design specifications, and handoff bundles from prior development milestones.

These documents are historical records preserved for provenance and are not maintained. Where any archived document conflicts with current guides in `docs/` or `docs/maintainer/`, current documentation is authoritative.

---

## Contents

- **`plans/`:** 38 dated design specifications and implementation plans from earlier releases.
- **`codemode-handoff/`:** Checksummed handoff bundle for the codemode contract implementation.
